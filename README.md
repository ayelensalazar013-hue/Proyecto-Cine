# Introducción
Administrar un complejo de cines que tiene varias sedes en distintos centros comerciales suele volverse desordenado si la información no está centralizada; cada sucursal cuenta con una cantidad diferente de salas, capacidades propias y estados operativos que van cambiando semana a semana. Cuando esos datos se manejan por separado, al armar la cartelera se corre el riesgo de cometer errores graves, como programar una película en un espacio que está en mantenimiento o calcular mal la cantidad de entradas disponibles por no conocer la capacidad real de la sala. Este proyecto surge para resolver ese problema mediante el diseño y desarrollo de una base de datos relacional que unifique toda la gestión del complejo, enfocándose en la exhibición de cine nacional.
Para lograr un funcionamiento ordenado, el sistema organiza la información partiendo de la infraestructura física de cada sede; se debe tener en cuenta que registrar correctamente los cines, las salas y el estado de las butacas condiciona todo el resto de la operación, ya que no se puede planificar una proyección ni vender entradas sin saber qué espacios están habilitados. Sobre esa base se vinculan el catálogo de películas certificadas por el INCAA y la programación semanal de funciones, incorporando controles concretos para evitar fallas en el uso diario. El sistema calcula el intervalo completo de cada proyección según la duración del film para impedir que se superpongan horarios en una misma sala, filtra la venta de entradas según la calificación oficial por edades establecida por la Ley N.º 17.741 y mantiene las funciones nuevas deshabilitadas hasta que el encargado confirma la grilla. Al mismo tiempo, se utiliza la baja lógica cuando un cine o una sala dejan de operar, de modo que se bloquea su uso futuro sin borrar el historial de ventas anteriores.
A nivel técnico, la estructura de tablas, claves y relaciones está desarrollada en SQLite y se conecta con un archivo llamado database.js que cumple la función de simular un servidor; esto permite probar las consultas y validar las reglas del negocio de manera directa y liviana. El diseño también contempla la lógica comercial propia de los espacios dedicados al fomento audiovisual argentino, diferenciando los tipos de función (como preestrenos, estrenos o funciones normales) para aplicar tarifas acordes a cada caso, ya que su funcionamiento responde a las regulaciones nacionales y no al modelo de las cadenas comerciales. Con esta estructura base resuelta, el sistema asegura la integridad de los datos desde el inicio y queda preparado para sumar a futuro otras herramientas, como la facturación completa o una página web de reservas para el público.
